# 🎲 Dice Rolling Simulator

This is a simple Python program that simulates rolling a six-sided dice. It's great for beginners who want to practice basic Python concepts like loops, functions, user input, and randomness.

## 🚀 Features

- Rolls a virtual dice with values from 1 to 6
- Option to roll again
- Adds a fun 🎲 emoji to enhance the experience
- Clean, beginner-friendly code

## 🧠 Concepts Used

- Python functions
- While loops
- Conditional statements
- `random` module
- User input
