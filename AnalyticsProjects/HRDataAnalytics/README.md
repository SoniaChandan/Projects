# HR Analytics Dashboard with Predictive Insights

This Streamlit app helps HR professionals visualize employee data, predict attrition, and explore key workforce trends using machine learning.

## 🚀 Features
- Upload CSV data
- Clean and preprocess HR data
- Interactive filters and department-level insights
- Predict employee attrition using Random Forest
- Visualize feature importances
- Download predictions as CSV

## 🛠️ Tech Stack
- Python
- Streamlit
- scikit-learn
- Pandas, NumPy, Seaborn, Matplotlib
